حزمة مبسطة لمشروع باحث PDF Pro Max

هذه الحزمة تحتوي على خمسة ملفات ظاهرة فقط بعد فك الضغط.
لا ترفع المجلدات المتداخلة؛ لا توجد مجلدات داخل ملف ZIP.

الرفع إلى GitHub:
1) ارفع CREATE_PROJECT.sh إلى الصفحة الرئيسية للمستودع.
2) أنشئ ملفًا جديدًا بمسار .github/workflows/android.yml.
3) انسخ محتوى الملف android.yml إلى ذلك الملف واحفظه.
4) ارفع الملفات الثلاثة الباقية إلى الصفحة الرئيسية إذا رغبت في الاحتفاظ بها؛ لا تؤثر في البناء.
5) افتح Actions ثم Build Bahith PDF Pro Max ثم Run workflow.

مهم:
- ملف android.yml داخل ZIP هو نص سير العمل فقط. يجب وضعه في المسار
  .github/workflows/android.yml حتى يتعرف GitHub Actions عليه.
- السكريبت CREATE_PROJECT.sh ينشئ بنية Android المطلوبة تلقائيًا.
- بعد نجاح البناء، نزّل APK من Artifacts.
- هذه نسخة تأسيسية لقارئ PDF: اختيار ملف وعرض صفحاته والتنقل بينها.
  لا تتضمن حاليًا OCR عربيًا أو ربط المكتبة الشاملة أو البحث الشامل.
- لا يمكن ضمان نجاح البناء قبل تشغيله في GitHub Actions؛ راجع سجل الخطأ إن فشل.
